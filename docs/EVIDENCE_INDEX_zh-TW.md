## 未公開的完整原件

`results/` 已列入 `.gitignore`。完整原件不公開的原因：其中含本機路徑、帳號與其他應用程式的視窗中繼資料，也含未經整理的失敗輪次；這些檔案保留做為追溯依據，**不刪除、不改寫**，也不因被忽略而視為可清理。

因此，11/17 Raw30／60 的主機送幀數可由公開的 `diagnostics.csv` 依 `stream_begin` 原點重算；其他實機數字對乾淨 clone 而言是**可依程序重做、但不能從 Git 重算**的結果。凍結 App／CLI 只公開 SHA256，不公開檔案。需要重算時，向原機器擁有者索取指定實驗目錄，並核對檔案清單與 SHA256；缺少原始檔的摘要不能當成可重算的量測。

## 重做一輪實機短測的最低紀錄

為讓結果能被其他人審核，每輪至少保存：

1. 來源 commit／tree，以及凍結 App／CLI 在執行前、執行中、執行後的 SHA256。
2. 完整命令與環境變數（含 `MSU2_SHARED_LOCK_ROOT`、`MSU2_DIAGNOSTICS`）、開始／結束時間、退出碼、stdout／stderr。
3. 執行前後兩個序列埠別名（cu／tty）與鎖檔的 owner 檢查原始輸出，以及確認沒有其他 MSU2 程序的輸出。
4. 該輪的 `stream_*.csv`、`diagnostics.csv`、`events.log` 原檔，以及畫面內容的說明（桌面是否變化、使用哪個內建來源）。

鎖檔在程序結束後仍會留在磁碟上，檔案存在或內含舊 PID 不代表仍被占用；以當下 owner 檢查為準。停止條件、序列埠擁有權與凍結規則見[交接入口的實機規則](HANDOFF_zh-TW.md#實機工作規則)。

公開摘要只寫數字、條件與判讀邊界，不放本機絕對路徑、帳號、其他應用程式名稱或視窗標題。
