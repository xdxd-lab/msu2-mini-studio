# 現況與待辦

更新日期：2026-11-05。產品為原生 macOS 工程開發版本；`Info.plist` 標示 0.2.0（build 2），不是已通過正式發行驗收的版本。

## 可重現的軟體基線

來源 `359119a` 的 [GitHub macos-14 CI](https://github.com/xdxd-lab/msu2-mini-studio/actions/runs/41939938456) 已通過 App／CLI 建置、完整離線套件、ASan／UBSan 及 hardware driver 連結。driver 未執行；測試未操作 USB、擷取桌面或驗收 Flash 持久性。

這一版將診斷 writer 從 Controller 分離；另修正測試對 20 ms 內至少兩次 payload 寫入的排程假設，保留短預算中止與逐塊剩餘預算遞減的檢查。產品 Session、ACK 規則及 timeout 沒有因此改動。舊測試的延遲注入可重現同樣失敗，但首輪 CI 沒有記錄預算值，不能證實當時的確切延遲。

## 下一步的優先順序

| 優先 | 問題 | 下一個有資訊增益的工作／完成條件 |
|---|---|---|
| 1 | Pair ACK 逾時與恢復 | 以同內容與受控條件區分編碼、實際送出率及裝置會話因素；保留失敗階段，不改 ACK 接受規則；之後需可重現的長時間串流與恢復證據 |
| 2 | 簽章與升版授權 | 在穩定簽章身分下驗證更新前後精確 App 路徑、螢幕權限及重新啟動；目前 ad-hoc 重建仍可能需授權 |
| 2 | 素材 Flash 寫入 | 指定可犧牲資料，驗證擦除語意、讀回、相鄰資料、取消、備份還原及斷電後持久性；現有離線測試不足以代替 |
| 3 | 分區公平性與桌面時效 | 釐清 center3 左區飢餓，量測各區更新率與最舊區域年齡；主機更新計數增加不等於完整桌面更即時 |
| 3 | 資源與診斷穩健性 | 長時間 RSS／CPU／執行緒／檔案描述元量測，安全注入寫檔失敗及緩衝溢位；未量測項目不宣稱已改善 |
| 待查證 | 控制層請求邊界 | 程式閱讀發現 close 後清除 disconnect 旗標的位置與 `set_flags` 鎖規則不同；先用受控的重複請求情境確認是否有可見影響，目前未重現問題 |
| 發布前 | 發行與支援範圍 | 完成[發布準備](RELEASING_zh-TW.md)；Intel／通用 binary、公證及獨立 CMake 路徑不在現有驗證範圍 |
