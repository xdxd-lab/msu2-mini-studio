交付結論

   完整名稱、內建 pattern 及自訂 PPM 路徑保留。

本輪沒有執行物理測試，也未建立 LCD 完成回覆或根因已修復的結論。

實作與紀錄

Python 以 None 區分未指定 hold：send 使用 13，stream 使用 0 且命令不傳
hold 旗標。stream 明確指定非零 hold 仍拒絕，未增加每幀或結束時等待。
數字編號依預製完整名稱的數字前綴解析，未知或歧義編號在啟動前拒絕。
靜態編號 8/9 仍是 PPM，沒有改成動態 gradient/noise pattern。
metadata 保存 kit_version、source_requested 原輸入、source 完整名稱、
有效 hold_open_ms 及 hold_open_ms_explicit，保留原執行與守衛證據欄位。

C++ main.cpp 相對舊 hold-open 封裝只有版本、help、send 預設值三行變更。
CMake 的 project VERSION 同步為 0.3.1；README 與 PTY 測試另有必要更新。
其他 src/include 與舊封裝一致，協定、傳輸、局部更新及分區演算法保留。
